# Swarm integration in this tree

`btxd` watches `catalog.json` while ModelNet is enabled. A byte-verified complete model becomes an observer subscription in `modeldir/swarm/observers.json` and a mesh record in `modeldir/swarm/mesh-state.json`.

The lineage id is not the artifact id or the checkpoint id. A provisional lineage stays private. A local mapping is the only public advertisement. Neighborhood selection, role eligibility, and the device governor run in this process. With no `swarm/device.json`, the node offers public seeding and CPU evaluation, records zero VRAM, and does not train. GPU training, private prompts, and private data stay off until that file grants them. `automatic_spend_atoms` stays the string `"0"`. The scheduler has no spend key. There is no swarm startup flag and no second swarm binary. Many pools share one channel. A clearing batch nets every payment in that batch and advances the channel sequence once. The update builds no layer-1 transaction. A reservation of the same atoms by a second pool is refused, and a reorg freezes new reservations. One close template lists each positive pool balance. A promise, an observed output, an escrow lot, channel capacity, earned credit, and a confirmed settlement stay separate, and a certificate is not a balance. Findings, strategies, adapters, and candidates append to separate timescale arrays. The committee log writes a vote before it returns and refuses to truncate a committed prefix. A mandate reserve cannot exceed remaining collateral. An attempt lease refuses another result until the worker is quiescent and expires without resetting accepted work. A KV prefix mismatch is not an absent engine, and a prefetch without an engine moves no bytes. A LAN card verifies an ML-DSA signature and refuses a private membership advertisement. Follow stages a compatible candidate without changing the active head. This process can bind a refund and cannot broadcast the funding transaction. A watchtower appointment requires a contest window of at least 160 blocks and refuses a native remedy and a secp256k1 penalty. A transport pin does not authorize a payment. Joining a work realm does not join the controller committee. A poisoning freeze keeps the prior checkpoint, and a key compromise does not remap identity history. A ciphertext piece is `REALM_SEALED` and is not decrypted. An invalid eviction deletes nothing. A remote manifest does not start a host interpreter, and this process does not launch a sandbox child.

Exact KV placement, cohort averaging, the reference integer trainer check, Hoeffding qualification, niche allocation, channel stage and rollback, SEP pool balances, contributor HTLC lots, the cumulative channel, and routed payment plans are library calls inside `bitcoin_modelnet`. A missing GPU or transfer engine returns `ENGINE_ABSENT` and moves no bytes. HTLC scripts are the existing P2MR claim and refund leaves. Nothing in this path broadcasts a transaction.

`contrib/swarm` remains the reference package. `btxd` does not start it. The sidecar patch is not applied.

A quality graduation does not promote a realm and does not admit ExactReplay. Lineage ancestry, presence, knowledge records, learner-island forks, SEP/1 manifests, reward splits, refund and payout templates, hashlock remedies, sponsor lots, evaluator thresholds, and recovery checks live in this process. A second policy epoch does not move old obligations. The same outpoint cannot fund two pools. This host can run the Linux unit suites. A Windows or GPU run is recorded only when that command is executed on that machine.
